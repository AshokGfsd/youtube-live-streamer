Video discovery

Find videos for your stream

Search Instagram by topic, then collect clips for a new live playlist.

Uses only your signed-in private Chrome session and visible Instagram Search results. Results depend on what Instagram loads; the requested count is not guaranteed. No login or CAPTCHA bypass.

If the terminal works but this probe returns 404, use Copy exact selected URL and test that same URL using a normal ffprobe command. The probe now uses the same supported options as the Codespaces FFprobe installation. Only HTTPS Instagram/Meta CDN MP4 links are accepted initially; signed video URLs may expire or redirect. Imports stay in browser memory and are not saved to Git or MySQL. Stream only content you have permission to rebroadcast.
